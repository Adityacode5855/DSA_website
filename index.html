O(N)

Time Complexity

Every node in the tree is visited exactly once during the recursive traversal. At each node, swapping the two pointer references (left and right) is an $O(1)$ constant time operation. Hence, total runtime scales linearly: $T(N) = 2T(N/2) + O(1) \implies O(N)$.

O(H)

Auxiliary Space Complexity

Auxiliary space is dictated entirely by the maximum depth of the call stack during recursion. For a balanced binary tree, the height $H = \lceil \log_2(N+1) \rceil \implies O(\log N)$. In the worst degenerate case (e.g. left or right skewed tree), $H = N \implies O(N)$.

C++17 & WASM

Memory & Execution Engine

Tree nodes are allocated in WebAssembly linear memory. Pointer manipulation occurs via 32-bit offset loads/stores. Native C++17 binary tree_mirror.exe runs directly via MinGW GCC, guaranteeing zero garbage collection overhead.

How It Works: Recursive Hierarchy Inversion

1. The Practical Scenario

Modern vector diagramming tools (such as Lucidchart, Miro, and Figma) frequently need to invert hierarchical charts horizontally. Key applications include:

  • Localization & RTL Support: Flipping organizational charts and decision trees for Right-to-Left writing systems (e.g. Arabic, Hebrew, Urdu).
  • Compiler Abstract Syntax Trees (AST): Inverting binary expression trees to convert operators or verify associative symmetry.
  • Graphic Layout Engines: Mirroring branch layouts for balanced visual aesthetic in mind maps and dependency graphs.

2. The Divide & Conquer Recursive Algorithm

At any given node root:

  1. Base Case: If root == nullptr, return nullptr.
  2. Recurse Left: Mirror the left subtree: leftMirrored = mirror(root->left).
  3. Recurse Right: Mirror the right subtree: rightMirrored = mirror(root->right).
  4. Swap: Swap pointers on the current node: root->left = rightMirrored; root->right = leftMirrored;.
  5. Return: Return root.

3. Mathematical Induction Proof

Base Step: An empty tree or single-node tree has its children vacuously inverted.
Inductive Hypothesis: Assume mirror(root->left) correctly produces the mirror reflection of the left subtree, and mirror(root->right) correctly produces the mirror reflection of the right subtree.
Inductive Step: Swapping the mirrored right subtree to the left and the mirrored left subtree to the right produces the complete geometric reflection across the vertical plane. By induction, the algorithm holds for all finite binary trees of size $N \ge 0$.
